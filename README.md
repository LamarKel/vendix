# Vendix

POS y facturación electrónica (e-CF DGII) para comercios minoristas de República Dominicana:
ferreterías, minimarkets, colmados y tiendas.

- Punto de venta (normal y táctil), cajas y arqueos
- e-CF tipos 31, 32, 33 y 34, comprobantes tipo B y secuencias NCF
- Productos con presentaciones y unidades de medida, listas de precio, promociones
- Inventario con kardex y mermas, compras, órdenes de compra y devoluciones a suplidor
- Clientes con crédito (CxC), cuentas por pagar, cotizaciones y reportes 606/607/608

Stack: Laravel 12, Filament 4, PostgreSQL 18, Laravel Sail.

Instalación local: ver `docs/instalacion-local.md`. Reglas del proyecto: `CLAUDE.md`.
